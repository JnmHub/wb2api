# v2.6.1 — 华为渠道登录打通，导入与积分显示补齐

v2.6.0 把 CodeArts 渠道接了进来，但只有真机跑过才知道哪几段是纸面上的。这一版
修掉三个只有真实登录才暴露的坑，并补上导入、积分显示和几处数据卫生。

WorkBuddy 两个出口行为不变。

## 登录：三处真机才暴露的错

**1. 回调链路缺失。** 华为的 ticket 必须用 **portal 下发的 secret** 才能轮询，而 secret
是浏览器回调到 `127.0.0.1:<port>/oauth/callback` 时送回来的。v2.6.0 里授权链接的
`port=0`、网关也没有回调路由，于是永远 `TM.00001001 无效 ticketId`。

现在每次点「开始登录」会开一个**独立的临时回调端口**（`127.0.0.1:<随机端口>`），
授权链接里就带这个端口。好处是：多开标签页、重复点击都不会把「A 次尝试的 code」跟
「B 次尝试的 verifier」配错（那正是第二版报 `STS5.1805 invalid authorization code` 的原因）。

**2. token 端点主机写错。** 授权码兑换和 refresh 要打
`https://sts.cn-north-4.myhuaweicloud.com/v1/oauth2/tokens`，而不是 snap-access 下的
`/snap-manager/...`。后者回 `APIG.0101 API does not exist`。这个错同时让**续期整条链**
失效，只是之前没真机跑过。

**3. token 响应不一定带身份。** `/v1/oauth2/tokens` 只保证返回 AK/SK/security_token，
`user_id` 可能是空的。现在用新拿到的 STS 令牌调 `snap-manager/v1/current/user` 解析身份，
再建号。

另外：同一 code 被浏览器重放时返回缓存结果（授权码一次性）；兑换失败不再终结会话，
面板的票据轮询会继续跑，失败页会打印 `redirect_uri`、端口和 code 长度便于定位。

### 真机验证结果

```
登录          → 账号 88fd2a8b… 入库，14 个模型自动发现
聊天          → POST /v1/chat/completions (X-Realm: codearts) model=GLM-5.2 → "在线"
续期          → 手动 refresh 后 expires_at 23:09:37 → 23:10:49，status=ready
```

## 账号导入支持

以前导入器要求 `accessToken` 是 JWT，华为的不透明 STS token 一律被判非法，只能登录或
手工丢文件。现在按行自动识别 CodeArts 凭据：

- 识别：`realm=codearts`、存在 `codearts` 对象，或出现 `cloud_dragon_token` /
  `security_token` / `access_key_id` / `user_id`
- 支持三种形状：codexarts 的 auth json（snake_case）、本网关账号文件（`codearts` 嵌套）、
  扁平 camelCase
- 强制渠道不会误伤：选了「国际版」也会落到 `codearts`
- 必需：`user_id` + `security_token` + `access_key_id` + `secret_access_key`；
  `refresh_token`/`dpop_private_key`/`code_verifier` 缺失时能用，但 2 小时后无法续期

同时修了一个泄露：secret-free 导出以前只删 `accessToken`/`refreshToken`，而 AK/SK 存在
`extra.codearts` 里会一起导出。现在连 `codearts`（含 DPoP 私钥）一起剔除。

## 面板

- **签到 / 积分**：列表「积分」列对华为账号显示签到领取量（`+4000`），详情面板新增
  「签到 / 积分」行（结果 + 时间）。后端新增 `checkinView`，把 WorkBuddy 的字符串时间戳和
  华为的对象统一成一种形状
- 头像标识：`cn→CN`、`codearts→HW`、其他 `GL`
- 导入弹窗给出 CodeArts 字段提示
- **自动重载**：懒加载 chunk 在重建后会 404（表现为「面板打不开」），现在监听
  `vite:preloadError` 自动强刷一次，带 30 秒防抖

## 数据卫生

- **福利源 4000 不再是错误**：`invalid channel, group not found` 表示账号没有免费套餐分组，
  现在当作「无福利资格」，不写进账号的 `models_error`
- **过滤非法 UTF-8 模型 id**：上游 builtin 列表里有一个损坏条目，以前会原样出现在
  `/v1/models`
- **签到不降级**：同一天第二次签到（调度器与手动点击撞车）不会再拿「无可领取」覆盖掉
  真实的「+4000」

## 已知边界

- **积分余额查不到**：逆向出的端点集合里没有余额接口（codexarts 自己也是
  `credits: 0 // 未查询真实余额`）。面板显示的是「签到领取量 + 今日 token 消耗」，
  不是账户余额
- **STS 有效期 2 小时**是上游定的，到期前 15 分钟自动用 refresh_token 续
- **单账号并发默认 3**（`WB_CODEARTS_INFLIGHT` 可调），占满时本地换号，不会把第 4 条打到上游
- 面板未做真实浏览器布局验收（只有 tsc + jsdom 用例）

## 升级说明

- 无需迁移；已有 CodeArts 账号文件直接可用
- `-panel-password` 只在启动时覆盖一次，之后不带该参数启动会沿用已保存的密码
