# wb2api v2.12.2

## CodeArts 与小浣熊的历史裁剪

- 在「设置 → 上游与提示词」中分别设置两个渠道的历史裁剪阈值，单位为 MiB。支持 0.8 等小数，设为 0 可关闭。保存后对新请求生效。
- 网关按最终发往上游的 JSON 字节数计算，从最旧的完整轮次开始移除。保留系统与开发者消息、当前轮及相关工具调用和工具定义。保留内容超过阈值时继续转发。
- 发生裁剪时，下游响应的输入 token 数会加上已裁历史的估算值，并标记 input_tokens_estimated。缓存和推理明细继续按协议返回。网关内部按上游实际用量记录。

构建产物包含 Linux amd64 和 arm64 二进制及各自的 SHA-256 校验文件。
