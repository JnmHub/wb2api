# v2.7.2 — 服务器部署也能登录了：把回调地址粘回面板

华为的 OAuth 授权页只允许回环回调：浏览器登录完成后一定跳到
`http://127.0.0.1:<随机端口>/oauth/callback?code=…`。

网关跑在你自己的机器上时这没问题；跑在**服务器**上就必然失败——那个 127.0.0.1
指的是操作者笔记本，不是服务器。表现就是登录完之后页面打不开，面板一直等着。

```
http://127.0.0.1:52917/oauth/callback?code=sh1owRx…&state=846f6b3c…
```

## 新增：粘贴回调地址

登录弹窗里多了一个输入框：

1. 点「开始登录」，在浏览器里完成华为登录
2. 授权后浏览器会跳到一个**打不开的** 127.0.0.1 地址——没关系
3. 把**地址栏那一整行**复制，粘进面板的输入框
4. 点「用这个地址完成登录」，网关用服务端保存的 PKCE verifier + 端口把 code
   换成凭据，账号直接落盘

接口（面板已经接好，脚本也能直接调）：

```
POST /api/v2/codearts/login/complete
{"attempt": "<登录会话 id>", "url": "<地址栏那一行>"}
```

- 接受完整 URL、`?` 后面的 query 串、或裸的 code
- 登录会话有效期 10 分钟，`attempt` 用「开始登录」返回的 `state`
- 授权码**一次性且几分钟就失效**，必须在发起它的那次登录里用
- 失败会给出人话提示：`STS5.1805` → 「授权码已失效，或与本次登录会话不匹配」

## 不用升级也能用的临时办法：SSH 端口转发

如果你不想等发版，把服务器的回环端口映射到本机即可，回调就能打通：

```bash
ssh -L 52917:127.0.0.1:52917 user@服务器
```

（端口取「开始登录」返回的 `callback` 里的那个数字，每次登录都会变。）

## 顺带修的

- 粘贴一个没有 `code` 的地址（比如只有 host）不再被当成授权码发出去，
  而是明确提示「地址里没有 code 参数」
- 只有 `secret` 的那一次回调（门户的第一跳）现在会被识别并提示
  「已收到 secret，请继续把带 code= 的那一次粘进来」
