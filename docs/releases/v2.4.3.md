# v2.4.3 — 与上游 1.7.17 ~ 1.8.0 对齐的 17 项改进

这一版把上游 10 月那些「我们也踩过」的坑逐条补齐：先修正确性，再补能力，最后是体验。
所有新开关默认取安全值，数据库不需要迁移，用量/配额/调度的既有语义不变。

## 修复

1. **签到不再把「处理中」当成功**：上游返回 `200` + `code=10001`（请求处理中）时不再记为已签到，
   改为待重试；已签到/重复签到仍按幂等成功处理。
2. **网页每日活跃释放会话**：拿到会话后无论成功失败都关闭，失败再删除，撞到 10 条会话上限
   先清最旧；重试从指数退避改成线性退避，并加每日预算，避免把账号打成风控。
3. **keepalive 提前量有兜底**：提前量至少为扫描间隔的 2 倍（默认 15 分钟），
   扫描变慢时不会出现「到期了才发现」。
4. **模型级 429 冷却持久化**：模型冷却写回账号记录，重启/换副本后仍然生效，过期自动清理。
5. **只有思考没有正文算失败**：三协议一致处理（Chat/Responses 5xx、Messages `error` 帧），
   不再把「空回复」当成功返回给客户端，也不会因此给账号记一次成功。
6. **免费额度错误只封锁该账号该模型**：上游 `11158` 现在会持久化 24 小时，其它账号/模型不受影响。
7. **品牌句清洗覆盖 assistant**：上游会把 assistant 里残留的品牌句判成 400，
   所以作用域扩到 `system` + `assistant`；`user` / `tool` 内容保持原样。

## 新增能力

8. **SSE 心跳**：流式默认每 15 秒发一次注释帧，长思考不会被中间设备当空闲连接掐断；
   心跳写失败立即取消上游，不占用槽位。
9. **Key 级账号白名单**：可把 API Key 限制到指定账号；未列入的账号（包括 `/u/<ref>` 显式前缀）
   一律 403，会话亲和不会绕回被禁账号。
10. **账号「参与每日任务」开关**：关掉只影响签到/活跃/保活，正常取号不受影响。
11. **会员档位**：面板显示付费/免费与到期时间，便于判断免费额度回退。
12. **思考档位映射**：把 `none/low/medium/high` 映射成上游实际档位，避免 `11150`。
13. **模型别名**：`claude-*` 之类的客户端模型名映射到真实模型，大小写不敏感，
    在封锁/限额/选号之前解析；`/v1/models` 会同时列出别名（`alias_of` 指向真实 id）。
14. **只列出可用模型**：可让 `/v1/models` 只返回当前池里真的能用的模型（默认关闭，保持全量）。
15. **会话键补充 `prompt_cache_key`**：除 header/`metadata` 外也认这个字段，缓存粘性更稳。
16. **更新检查启动先查一次**：启动后一两分钟内先查一次，之后按设定间隔。
17. **日志异步写入**：stdout/stderr 走有界队列，慢终端不再拖住请求路径；丢弃条数单独计数。

## 默认值与兼容性

- 模型别名默认为空、只列可用模型默认关闭、账号白名单默认为空、任务开关默认开启、
  心跳默认 15 秒 —— 不配置就是旧行为。
- 设置新增键（`model_aliases`、`models_only_available`）与账号新增字段（`tasks_enabled`、
  `tier`、`model_blocks`）都向后兼容，旧记录缺省即旧语义。
- 不需要数据库迁移；用量账本、配额、并发槽位、会话亲和语义不变。

## 验证

- Windows：`go vet ./...`、`go test ./... -count=1 -p=1`
- Linux（CI）：`-race` 全量 + PostgreSQL/Redis 集成用例
- 前端：`tsc -b --noEmit`、`vitest`

## 升级

1. 停旧副本（旧版用量 writer 不能与新版混跑），保留每个副本自己的 outbox。
2. 替换二进制或 `docker compose up -d --build`，不要 `down -v`。
3. 需要账号白名单/别名时在面板「设置 → 模型路由」与「API Key」里填，保存即生效。
4. 若自定义过保活扫描间隔，确认提前量已自动抬到间隔的 2 倍以上。
