# v2.11.0 · CodeArts 账号、每日签到和聊天协议

- 账号页显示 CodeArts 的签名凭据到期、续期重试时间和需重登状态。支持导入 Agent2API 的 CodeArts 导出，保留刷新绑定。并发续期按凭据版本合并，遇到限流遵守服务端重试时间。
- 任务页新增 CodeArts 每日签到，按北京时间和上游活动类型识别，提供当日补跑、单次触发及领取、待确认和续期状态。每日签到与注册活动分别处理。
- `/v1/chat/completions` 按完整 SSE 事件解析 Unicode，保留工具调用及推理数据。流式输出先发送结束原因，再发送客户端请求的用量帧，最后发送 `[DONE]`。
- CodeArts 选号按账号的模型权限、额度与容量执行，结合上游会话租约和显式会话绑定。长请求受首片段总等待预算约束，用量明细记录实际尝试账号及分段耗时。
