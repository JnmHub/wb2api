# v2.10.1 · 修复 CodeArts 输出预算过大和用量记录漏记

CodeArts 现在将超过 65,536 个 token 的整数输出预算收至 65,536。规则同时适用于客户端指定的预算和模型目录补入的默认值。例如，`deepseek-v4.1-flash` 的目录默认值 128,000 在发往 CodeArts 时会降至 65,536，显式指定的 4,096 则按原值发送。

用量记录的 `request_shape.max_tokens` 现在取自本次实际发往 CodeArts 的输出预算。管理员可以用请求 ID 核对普通 HTTP 错误和流内错误的记录，判断该请求使用了哪个预算。

本次修复针对输出预算超出边界引发的参数拒绝。上游业务码 `InferHub.001001005.400` 也可能由其他参数触发。
