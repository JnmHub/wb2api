# wb2api v2.12.0

## 小浣熊渠道

- 新增 `raccoon` 渠道、账号导入、模型目录、会话绑定、积分查询和每日签到。Chat Completions、Responses 和 Messages 按账号支持的模型调度，模型别名共享禁用和冷却状态。
- JWT 被上游拒绝后会按凭据类型判断是否续期。可续期账号遇到 429 时按退避时间重试，IAM 账号失效后需要重新登录。
- 回调校验登录状态，账号保存核对凭据版本。脱敏导出清理嵌套凭据。后台操作的结果不会覆盖已经换新的凭据。

## CodeArts 与 WorkBuddy 兼容

- CodeArts DeepSeek 将拆分在多个数据帧中的思考标签与正文分开处理，空的响应包装不会作为正文输出。
- 大请求按需清理旧轮次历史中的可移除推理内容，并在最终请求体上完成签名。
- CodeArts 和小浣熊在优雅关停时等待已经开始的 Token 交换完成并保存结果。WorkBuddy 的定时任务与小浣熊签到独立执行。

## 账号导入与回滚

- 提供三渠道账号模板和默认预演的推送脚本，支持逐条结果、分批提交及旧版本识别。详见 [账号导入对接](../PUSH_API.md)。
- 本版启动时会迁移小浣熊账号和专用 API Key 的持久化格式。回滚到不支持小浣熊的旧版时，这些账号和 Key 会被旧版跳过。恢复本版后可以继续使用。通用 Key 仍按旧版自身的渠道规则处理，账号导出的 JSON 格式保持兼容。

构建产物包含 Linux amd64 和 arm64 二进制及 SHA-256 校验文件。
